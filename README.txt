PANDUAN:
1. Buat Google Spreadsheet.
2. Extensions > Apps Script.
3. Tempel Code.gs.
4. Ganti SPREADSHEET_ID dengan ID Spreadsheet.
5. Deploy > New deployment > Web app.
6. Execute as: Me; Who has access: Anyone.
7. Salin URL Web App.
8. Di index.html, ubah const API_URL="" menjadi URL Web App.
9. Upload index.html ke hosting.

DATA:
Nama Kegiatan | Jenis Kegiatan | Nomor Surat Tugas | Pembuat Laporan | Status | Tanggal Kegiatan | Tanggal Penyerahan Ke Keuangan | Penerima di Keuangan | Jumlah Anggaran | Tanggal Pencairan | Keterangan

Fitur:
- Input data dari HP
- Tersimpan ke Google Sheets
- Daftar, pencarian, detail
- Rekap total/diproses/selesai
- Format Rupiah
- Status dropdown
- Data contoh untuk demo

Untuk data internal kantor, tambahkan autentikasi sebelum digunakan secara luas.
